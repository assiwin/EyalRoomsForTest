אפליקציה לשיבוץ חדרים לנבחנים — גרסה 6

הפעלה מחבילת הפרויקט

  1. חלצו את כל קובץ ה־ZIP לתיקייה רגילה.
  2. לחצו פעמיים על Start.cmd.
  3. בהפעלה הראשונה בלבד נדרש אינטרנט להתקנת סביבת ההרצה המקומית.
  4. הממשק נפתח בדפדפן, אך הנתונים מעובדים במחשב המקומי בלבד.

שיבוץ חדרים

  1. טענו XLSX או XLSM הכולל גיליון dbase.
  2. רק תלמידים המסומנים 1 בעמודה J משתתפים.
  3. השלימו קיבולת לחדרים מיוחדים, אם נדרש, ולחצו „חשב שיבוץ”.
  4. בדקו את המטריצה והורידו את קובץ השיבוץ. עמודה I מתעדכנת והמאקרו נשמר.

דפי מעטפות

  1. לאחר שיבוץ תקין בחרו שכבת מבחן: י׳, י״א או י״ב.
  2. אפשר להוסיף עד שתי הערות ולבחור את החדר שבו תופיע כל הערה.
  3. לחצו „הפק דפי מעטפות PDF”.
  4. כל חדר מקבל עמוד A4 עם רשימת נבחנים, התאמות וסיכום לפי יחידות.
  5. הקובץ נשמר בתיקיית Output ואפשר גם להורידו מהמסך.

מתקין יחיד למשתמשי Windows

במחשב הפיתוח התקינו Python 3.12 ו־Inno Setup 6 והפעילו Build_Installer.cmd. ייווצר installer_output\ExamRoomApp_Setup_v6.exe. משתמש הקצה מתקין קובץ יחיד, מקבל קיצור דרך ואינו זקוק ל־Python. לאחר ההתקנה ניתן למחוק את המתקין.

מיועד ל־Windows 10/11 בגרסת 64 ביט. מתקין שאינו חתום עלול להציג אזהרת SmartScreen.
