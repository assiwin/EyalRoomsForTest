אפליקציה לשיבוץ חדרים לנבחנים — גרסה 6
נוצר על ידי אסי וינברגר

הפעלה מחבילת הפרויקט
====================
1. חלצו את כל קובץ ה-ZIP לתיקייה רגילה.
2. לחצו פעמיים על Start.cmd.
3. בהפעלה הראשונה בלבד תותקן סביבת ההרצה המקומית. נדרש אינטרנט בשלב זה.
4. האפליקציה נפתחת בדפדפן, אך כל עיבוד הנתונים נעשה במחשב המקומי.

הפקת דפי מעטפות
================
1. טענו קובץ XLSX או XLSM ובצעו שיבוץ תקין.
2. באזור "הכנת דפי מעטפות" בחרו שכבת מבחן: י׳, י״א או י״ב.
3. ניתן להוסיף עד שתי הערות ולבחור לאיזה חדר שייכת כל הערה.
4. לחצו "הפק דפי מעטפות PDF".
5. ניתן להוריד את הקובץ, לפתוח אותו או לפתוח את תיקיית Output.

קובץ ה-PDF כולל עמוד A4 לכל חדר, רשימת תלמידים, יחידות, מורה,
תוספת זמן, הגדלה, הקראה, שדות נוכחות והגשה וסיכום לפי יחידות.
בדפי ההדפסה לא מופיעים קרדיט או מספור עמודים. הקרדיט מופיע בממשק בלבד.

בניית מתקין EXE יחיד
=====================
שלב זה מיועד למחשב הפיתוח בלבד:
1. התקינו Python 3.12 בגרסת 64 ביט ואת Inno Setup 6.
2. הפעילו Build_Installer.cmd.
3. בסיום יתקבל installer_output\ExamRoomApp_Setup_v6.exe.

המתקין מציג התקדמות, מתקין את האפליקציה ללא צורך ב-Python אצל המשתמש,
יוצר קיצור דרך בשולחן העבודה ובתפריט התחל ומוסיף אפשרות הסרה ב-Windows.
לאחר ההתקנה ניתן למחוק את קובץ ההתקנה.

האפליקציה והמתקין מיועדים ל-Windows 10/11 בגרסת 64 ביט.
המתקין אינו חתום דיגיטלית ולכן Windows SmartScreen עשוי להציג אזהרה.
