# EyalRoomsForTest

אפליקציית Windows Desktop ב-Python לשיבוץ תלמידים לחדרי בחינה ולהפקת מסמכי עבודה להנהלת הבחינות (מעטפות, דוחות מורים, מטריצה, זמני בחינה וסידורי ישיבה).

## גרסה

- גרסה נוכחית: **13.0.0**

## ייעוד הפרויקט

האפליקציה מיועדת לצוותי בחינות בבתי ספר. היא מאפשרת לטעון קובץ Excel, לחשב שיבוץ תלמידים לפי כללים פדגוגיים ותפעוליים, ולייצא תוצרים להדפסה ולשיתוף:

- קובץ Excel מעודכן עם תוצאות השיבוץ
- דפי מעטפות לכל חדר בחינה
- מטריצת מורים-יחידות-חדרים ב-PDF
- דוחות מורים וקובץ ZIP מרוכז
- רשימת הקראה (לתלמידים עם התאמת הקראה)
- סידורי ישיבה לחדרים רגילים

כל העיבוד מתבצע מקומית, ללא העלאת נתוני תלמידים לשירות חיצוני.

## קבצים מרכזיים

- `app.py` – נקודת הכניסה לאפליקציה, שרת מקומי (`127.0.0.1`) וניהול תהליך העבודה מקצה לקצה.
- `engine.py` – מנוע קריאה/אימות של קובץ ה-Excel, אופטימיזציית שיבוץ החדרים וכתיבת תוצאות.
- `envelopes.py` – הפקת PDF של דפי מעטפות לפי שיבוץ מאושר.
- `matrix_pdf.py` – הפקת PDF של מטריצת מורים-חדרים.
- `schedule_pdf.py` – הפקת PDF של חישובי זמני הבחינה.
- `teacher_reports.py` – הפקת דוחות תלמידים לפי מורה ואריזה ל-ZIP.
- `reading_list.py` – הפקת רשימת הקראה ב-PDF.
- `seating_plan.py` – שיבוץ מקומות ישיבה (עד 32 בכל חדר) והפקת תרשימי ישיבה.
- `database_import.py` – יצירה/עדכון של קובץ בסיס נתונים מבוסס גיליונות מורים.
- `workbook_management.py` – קריאה/עדכון גיליון ניהול ושמירת מיפוי חדרים פיזיים.
- `Start.cmd` – הפעלה למשתמש קצה: התקנה אוטומטית של סביבת Python והרצת האפליקציה.

## תכונות עיקריות

- שיבוץ תלמידים אוטומטי לפי יחידות לימוד, מגבלות קיבולת וכללי הפרדה.
- תמיכה בחדרים ייעודיים וחדרים מיוחדים.
- שחזור שיבוץ קיים מקובץ Excel כאשר הנתונים תקינים.
- שמירת התאמה ל-`XLSX`/`XLSM` תוך שימור מבנה הקובץ ו-VBA.
- הפקת מסמכי PDF בעברית (RTL) להדפסה תפעולית.
- שמירה ושחזור של מיפוי חדרים פנימיים לחדרי בחינה פיזיים.

## דרישות מערכת

- Windows 10/11 (64-bit)
- חיבור אינטרנט בהפעלה ראשונה (להתקנת Python וספריות, אם נדרש)

## התקנה והרצה

### למשתמש קצה

1. חלץ את קבצי הפרויקט לתיקייה מקומית.
2. הפעל `Start.cmd`.
3. בהפעלה ראשונה תתבצע התקנה אוטומטית של Python 3.12 ויצירת סביבה (`.venv`).
4. השאר את חלון ה-`cmd` פתוח בזמן העבודה.
5. הדפדפן ייפתח אוטומטית לממשק האפליקציה.

### הרצה ידנית (למפתחים)

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

## בנייה (אופציונלי)

- `Build_EXE.cmd` – בניית תיקיית הפצה באמצעות PyInstaller.
- `Build_Installer.cmd` – בניית קובץ התקנה באמצעות Inno Setup.
