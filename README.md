# EyalRoomsForTest

אפליקציה מקומית ל-Windows לשיבוץ חדרי בחינה ולהפקת דפי מעטפות.

- גרסה: 18
- עיבוד קובצי Excel נעשה מקומית במחשב.
- אין במאגר נתוני תלמידים או קובצי בית ספר.
- קובץ ההתקנה נבנה אוטומטית באמצעות GitHub Actions.

נוצר על ידי אסי וינברגר ואייל שיף.

כפתור „אודות” בפינה העליונה פותח חלון עם מספר הגרסה, הקרדיט ומידע על האפליקציה וקובצי הפלט.
