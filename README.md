# EyalRoomsForTest

אפליקציה מקומית ל-Windows לשיבוץ חדרי בחינה ולהפקת דפי מעטפות.

- גרסה: 28.0.0
- עיבוד קובצי Excel נעשה מקומית במחשב.
- אין במאגר נתוני תלמידים או קובצי בית ספר.
- קובץ ההתקנה נבנה אוטומטית באמצעות GitHub Actions.

נוצר על ידי אסי וינברגר ואייל שיף.

כפתור „אודות” בפינה העליונה פותח חלון עם מספר הגרסה, הקרדיט ומידע על האפליקציה וקובצי הפלט.

גרסה 19 כוללת אייקון מאויר של תלמיד ליד שולחן בחינה, בממשק ובקיצורי הדרך של Windows.

גרסה 20: עדכון קובץ קיים קורא את כל רשומות dbase בלי תלות בערך עמודת „משתתף”, מציג את ספירתן ומתריע על מזהה חסר או כפול.

גרסה 21: מעבר מפורש על כל רשומות dbase בעדכון, ודיווח על רשומות שלא נמצאו בקובץ המורים, גם ללא סימון השתתפות.

גרסה 28: טעינת תלמיד שמסומן אצל כמה מורי מתמטיקה באותה רמת לימוד כרשומה אחת, עם שמות המורים יחד; זיהוי ברור של סימון סותר בכמה רמות.
