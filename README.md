# EyalRoomsForTest

אפליקציה מקומית ל-Windows לשיבוץ חדרי בחינה ולהפקת דפי מעטפות.

- גרסה: 34.0.0
- עיבוד קובצי Excel נעשה מקומית במחשב.
- אין במאגר נתוני תלמידים או קובצי בית ספר.
- קובץ ההתקנה נבנה אוטומטית באמצעות GitHub Actions.

נוצר על ידי אסי וינברגר ואייל שיף.

כפתור „אודות” בפינה העליונה פותח חלון עם מספר הגרסה, הקרדיט ומידע על האפליקציה וקובצי הפלט.

גרסה 31 מפרידה בין 3 למב״ר בחדרים רגילים, וסופרת אותם יחד במצב „בודד בשולחן”.

גרסה 32 מוסיפה קליטת התאמות בגרות מקובץ משרד החינוך לפי קודי ההתאמה, תוך סריקת כל שורות המתמטיקה ושמירה על תוספת הזמן הגבוהה ביותר. היא גם קובעת שעת התחלה 09:45 כברירת מחדל ומציגה מב״ר בלוח הזמנים.

גרסה 34 מאפשרת לבחור חדר הקראה אחד או שניים, מציבה אותם אחרי חדרי הכיתות הייעודיות ולפני החדרים המצומצמים, ומסמנת אותם במטריצת המורים והחדרים ובמעטפות.

גרסה 27 רעננה את ממשק העבודה והוסיפה מסילת התקדמות לארבעת שלבי התהליך.
גרסה 21 הוסיפה עדכון מפורש של כל רשומות dbase, ללא תלות בערך עמודת „משתתף”.
