9.0.1

New in this version:
- Installer hotfix: force-close the old app and its packaged children, stop only legacy Python/cmd processes launched from the app folder, remove the previous install, and retry cleanup while preserving Output.
- Exam-grade selection moved to the main opening screen: י׳, י״א or י״ב.
- The selected grade is shown read-only in step 05 and written to every envelope page.
- Changing the grade invalidates previously generated envelope PDFs.
- The installer credit overlay was removed so it cannot cover setup buttons.
- Setup detects and silently removes an older installed version before installing Version 9.
- An uninstall shortcut is added to the Windows Start menu.
- Publisher and application credit remain in application metadata and application screens.

Previous version 8.0:
- Compact editable exam-time calculator on the main screen.
- Automatic end-time calculation with 25%, 33% and 50% extensions.
