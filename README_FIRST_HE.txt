אפליקציה לשיבוץ חדרים לנבחנים - הפעלה ב-Windows

1. יש לחלץ את כל קובצי ה-ZIP לתיקייה רגילה.
2. יש ללחוץ פעמיים על Start.cmd.
3. בהפעלה הראשונה Python וספריות החישוב יותקנו אוטומטית. הפעולה עשויה להימשך מספר דקות.
4. יש להשאיר את החלון השחור פתוח בזמן השימוש באפליקציה.

האפליקציה דורשת Windows 10 או 11 בגרסת 64 ביט.
אם המחשב מוגדר כ-32 ביט, תוצג הודעה ברורה ולא תתבצע התקנה שגויה.
במחשב שמדיניות הארגון חוסמת בו התקנת תוכנות, יש לבקש אישור ממנהל המחשב.

גרסה 7.0:
- ניתן להפיק עותק PDF של מטריצת המורים והחדרים המוצגת במסך.
- לאחר הפקת דפי המעטפות כפתור "הבא" פותח מסך למיפוי חדרים פנימיים לחדרים פיזיים.
- לאחר הזנת החדרים, הפעולה "שיבוץ תלמידים" מפיקה PDF נפרד לכל מורה.
- קובצי המורים נשמרים בנפרד בתיקיית Output ומורדים יחד בקובץ ZIP.
- לכל מורה מוצגים שמות תלמידיו וחדר הבחינה הפיזי.

גרסה 6.0:
- במסך התוצאות מוצגת מטריצת מורים, יחידות וחדרים.
- בקובץ המופק נוסף גיליון בשם "מטריצת שיבוץ".
- תעודות זהות אינן מוצגות במטריצה.
- חדרים החורגים מהתקרה הרגילה מסומנים באדום וסיכומים מסומנים בצהוב.
- תוקנה תאימות XML של גיליון המטריצה לפתיחה ב-Microsoft Excel.
- לאחר שיבוץ תקין אפשר לבחור שכבת מבחן ולהפיק דפי מעטפות ב-PDF.
- אפשר להוסיף עד שתי הערות לחדרים מסוימים.
- כל PDF נשמר גם בתיקיית Output ומכיל עמוד A4 לכל חדר.
- בתחתית כל מסך מופיע הקרדיט "נוצר על ידי אסי וינברגר".

יצירת מתקין יחיד למשתמשים:
1. במחשב הפיתוח בלבד יש להתקין Python 3.12 ו-Inno Setup 6.
2. הפעילו את Build_Installer.cmd.
3. בסיום ייווצר installer_output\ExamRoomApp_Setup_v7.exe.
4. משתמש שמתקין קובץ זה אינו זקוק ל-Python, לפקודות או לקובצי הפרויקט.
